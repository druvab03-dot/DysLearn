DysLearn Class 1 English - ILLUSTRATED MATERIALS

These are actual vector illustrations, not text-only lesson cards.

Folders:
01_alphabet_A-Z  -> A-Z with a related illustrated object
02_vowels        -> A, E, I, O, U with illustrated objects
03_numbers_1-10  -> numbers with counted visual dots
04_colours       -> actual colour swatches
05_simple_words  -> illustrated vocabulary cards

SVG files can be used directly by a React/Vite application as image sources.
The lessons.json file describes the material groups.
